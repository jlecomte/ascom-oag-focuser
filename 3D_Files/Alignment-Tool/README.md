# Alignment Tool

- Simple tool for aligning the gears on the helical focuser.
- This should place them in the appropriate position to interface perfectly with the stepper gears (at least it does in my case).
- Using most modern slicers you should be able to easily adjust the Z height of the model, without needing to use any 3D modeling software, if you find you require or prefer a different alignment.

# Usage

- Be sure to use this on a flat sturdy working surface.

## Method 1

- Place the helical focuser with the red end down into the alignment tool.
- Push the gear ring down onto the helical focuser until it is flush against the alignment tool.

## Method 2

- Push the gear ring down onto the helical focuser further down than where it should normally be (i.e. close to the helical focusers red ring).
- Then place the helical focuser into the alignment tool (red end down) and push down on the top of the helical focuser until it is flush with the working surface; this will cause the alignment tool to push the gear ring back up and into position.
